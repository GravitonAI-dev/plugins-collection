# test-local

Entorno de pruebas del Plugin & Skill Builder. Contiene una skill de ejemplo end-to-end y el catalogo de skills del marketplace.

## Contenido

- `contrato-alquiler/` — plugin de prueba con la skill `contrato-alquiler` (contrato de alquiler con arbol de decision de preguntas textuales que carga el asset).
- `use-cases/casos-de-uso.md` — casos de uso de la skill.
- `tests/test-run.md` — ejecucion del arbol de decision sobre dos escenarios (datos sinteticos).
- `CATALOGO.md` — catalogo de todas las skills del marketplace con su estado frente al estandar oro.

## Nota

Todos los datos son placeholders o sinteticos. No hay nombres ni datos de usuarios reales.
